## How to Use This List

1. **Verify before outreach** — each entry has been assessed via agent-browser but websites change. Visit the site yourself before sending a message. Confirm the website assessment still holds and note any recent changes.
2. **Find the principal on LinkedIn** — search paths are provided. Log into LinkedIn and search using the principal's name + firm name. Before messaging, look for recent posts, articles, or activity you can reference.
3. **Pick your template** from `/docs/07-outreach-templates.md` based on what you find:
   - Outdated/templated site (Yeske Buie, Sequoia, Forum, Halbert Hargrove) → Template A or C
   - No clear CTA/conversion path (Savant, Modera, BBR) → Template B
   - Growing but using template (Truepoint, MAI, Beaird Harris) → Template C
   - Active seminars/events (Carson Wealth, Yeske Buie) → Template D
4. **Personalize the context line** with the Personalization Hook from this list — these are genuine, specific angles that show you did your homework.
5. **Track in outreach-tracker.md** — log sends, replies, calls.
6. **Start Tier 1, work down** — the smaller, more approachable firms are more likely to respond. Build case studies before approaching the $20B+ firms.

## Expanding the List

Once this initial batch is worked through, additional sources:
- **NAPFA** (napfa.org) — fee-only advisor directory, filterable by location. Many smaller firms here with outdated sites.
- **XY Planning Network** (xyplanningnetwork.com) — younger/tech-forward advisors, often with DIY websites that need professional help.
- **Financial Planning Association** (plannersearch.org) — CFP professional directory.
- **SEC IAPD** (adviserinfo.sec.gov) — public RIA registration data with AUM and services.
- **Barron's Top 100 RIAs** — annual ranking, each entry has a website.
- **Financial Times 300 Top RIAs** — similar ranking, good for aspirational targets.
- **RIA Channel** (RIADatabase.com) — comprehensive RIA database with AUM, location, and key personnel.
- **Citywire RIA** — coverage of RIA industry moves, promotions, and M&A — great for timing outreach around leadership changes.
