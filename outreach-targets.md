## How to Use This List

1. **Verify the website before outreach** — visit each site, confirm it hasn't been recently redesigned, and note 1-2 specific things you could improve
2. **Find the principal on LinkedIn** — search "[Firm Name] CEO" or "[Firm Name] founder" to identify the decision-maker
3. **Pick your template** from `/docs/07-outreach-templates.md` based on what you find:
   - Outdated/templated site → Template A
   - No clear CTA/conversion path → Template B
   - Growing but using FMG/Advisor Websites template → Template C
   - Active seminars/events → Template D
4. **Personalize the context line** with something genuine from their site or LinkedIn
5. **Track in outreach-tracker.md** — log sends, replies, calls

## Expanding the List

Once this initial batch is worked through, additional sources:
- **NAPFA** (napfa.org) — fee-only advisor directory, filterable by location
- **XY Planning Network** (xyplanningnetwork.com) — younger/tech-forward advisors
- **Financial Planning Association** (plannersearch.org) — CFP professional directory
- **SEC IAPD** (adviserinfo.sec.gov) — public RIA registration data with AUM and services
- **Barron's Top 100 RIAs** — annual ranking, each entry has a website
- **Financial Times 300 Top RIAs** — similar ranking, good for aspirational targets
