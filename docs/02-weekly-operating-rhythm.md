# Signal — Weekly Operating Rhythm

This is the repeatable week that runs the business indefinitely. Adapt hours to your capacity; the ratios are what matter.

## Weekly Cadence (Ideal: 40–50 hrs/week)

### Monday — Research & Pipeline Feed (4–6 hrs)
- **Morning (3 hrs):** Research target businesses in your niche. Source 50 new leads from Google Maps, LinkedIn Sales Navigator, Instagram industry hashtags, local business directories, or industry association member lists.
- **Filter:** Run every lead through the ideal client signals checklist:
  - Professional/custom existing site (even if outdated)
  - Running paid ads (Google/Meta) — check via library or ad transparency tools
  - High customer lifetime value (one customer = $1K+)
  - Active on social or has existing marketing spend
  - Clear decision-maker identifiable
- **Afternoon (1–2 hrs):** Write personalized opening lines for each of the 50 — just the context sentence (the specific, genuine observation). Save these as drafts; you'll complete and send them across the week.
- **End of day:** Review last week's outreach metrics. What got replies? What didn't? Adjust this week's messaging template.

### Tuesday–Friday — Outreach & Build (6–8 hrs/day)
**Morning block (2 hrs): Outreach**
- Send 10 personalized messages/day using the Context → Value → Question structure.
- Follow up on 5-business-day-old non-responders ("Just checking you got my last message — no pressure either way").
- Respond to any replies within 24 hours. Fast replies convert.

**Core block (4–6 hrs): Build & Delivery**
- Active client project work: build/refine one section at a time using the AI workflow.
- Component library maintenance: after finishing any novel section for a client, extract and generalize it into the library for reuse.
- QA passes: run existing work against the high-end rubric (spacing, hierarchy, motion, responsiveness).

**End of day (30 min): Admin**
- Log outreach responses in tracker
- Update project checkpoints
- Prep next day's 10 messages

### Saturday — Strategy & System (2–4 hrs, optional)
- Review pipeline: how many outreach → replies → calls → proposals → closes? Where's the bottleneck?
- Improve one system: write a better email template, refine a component, add a reference site, tighten the sales script.
- Plan next week's target list.

### Sunday — Off
No work. This is a premium creative business, not a grind.

## Monthly Checkpoints
- [ ] Review pricing: have prospects stopped negotiating? Am I fully booked? Time to raise?
- [ ] Component library audit: what new modules were added? Are they tagged and documented?
- [ ] Case study draft: any completed project that produced a measurable outcome? Write it up.
- [ ] Niche validation: is the chosen niche producing quality leads? If not, consider narrowing or shifting.

## Quarter-End Review
- [ ] Revenue vs. target
- [ ] Average project value — is it trending up?
- [ ] Client acquisition cost (time spent on outreach / deals closed)
- [ ] Referral volume — are past clients sending new business?
- [ ] Pricing tier readiness: do I have the portfolio/testimonials to justify the next tier?
