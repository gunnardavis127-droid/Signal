# Signal — 90-Day Launch & Operating Plan

## Phase 1: Foundation (Days 1–14)
**Goal:** Every system documented, every tool installed, zero ambiguity on how work gets done.

### Positioning Setup
- [ ] Select primary niche from ideal client profile shortlist (law, medical/dental, SaaS, financial advisory, boutique fitness). Pick ONE to start — narrow enough to remove yourself from the commodity pool, broad enough for a pipeline.
- [ ] Write the one-line outcome statement for that niche: "I help [niche] turn their website into their #1 source of [specific outcome]."
- [ ] Build a simple personal/agency landing page using the component library (hero, proof section, process overview, contact — 4 sections max). This is your own site and the first live proof of the system. Must pass the high-end QA rubric before going live.
- [ ] Set up all tooling per the [tooling checklist](#) (Cursor + Claude models, Blender + MCP, GSAP/Three.js, local dev environment).

### Reference Library
- [ ] Curate 10–15 reference sites from SiteInspire/Godly filtered by "could I sell this structure for $5K–$20K?" — save front-end HTML of each via browser "Save As" into `/references/`.
- [ ] For each reference, extract and tag the specific patterns worth reusing (hero style, split-layout ratio, card grid style, motion vocabulary) into a simple reference index.

### Component Library (Initial Build)
- [ ] Build 6 core modules as production-ready HTML/CSS/JS components:
  - Hero (full-bleed media + headline + subheading + single CTA)
  - Split layout (50/50 and 25/75 variants)
  - Card grid (3-column, reusable for testimonials/products/news)
  - Services/features list-column section
  - CTA band (closing section, mirrors hero)
  - Footer (links, contact, brand recap — no dead ends)
- [ ] Each module: mobile-responsive, includes the standard motion vocabulary (staggered reveal: headline → subheading → image → CTA), and is skinnable (CSS custom properties for colors/fonts).

## Phase 2: Pipeline Activation (Days 15–45)
**Goal:** First 10 prospects contacted per week, first sales calls booked, messaging iterated.

### Outreach Cadence (Weekly)
- [ ] Monday: Research 50 target businesses in the chosen niche (find via Google Maps, LinkedIn, Instagram, industry directories). Filter for the ideal client signals: professional existing site, running ads, active on social, clear growth investment.
- [ ] Tuesday–Friday: Send 10 personalized messages/day (40/week). Follow the Context → Value → Question structure. Track in a simple spreadsheet or CRM.
- [ ] Follow up once on non-responders after 5 business days.
- [ ] Track response rates by message variant — iterate messaging weekly based on what gets replies.

### Sales Pipeline
- [ ] Book discovery calls from replies — aim for 3–5 calls by Day 45.
- [ ] Run every call through the 9-step closing framework (set tone → discover → paraphrase → qualify → present → state price → handle objections → ask for decision → next steps).
- [ ] Target: 1–2 closed projects by Day 60.

## Phase 3: First Paid Projects (Days 45–90)
**Goal:** Deliver 1–2 paid projects that produce case studies and testimonials, validating the system end-to-end.

### Delivery (5-Phase System)
1. **Intake** — discovery call/questionnaire, contract, deposit, asset collection. Lock scope before design starts.
2. **Planning** — sitemap, user journey, milestone timeline, technical decisions. Share with client for sign-off.
3. **Build** — execute section-by-section using the component library and AI workflow. Track against checkpoints.
4. **Revision** — QA against the high-end rubric (spacing, hierarchy, motion, responsiveness, accessibility). Fixed revision rounds (2 max). Deploy to staging for client review.
5. **Delivery** — walkthrough, go-live, 30-day support window, handover documentation.

### End-of-90-Days State
- [ ] 1–2 completed client projects with measurable outcomes
- [ ] 2–3 documented case studies / testimonials
- [ ] Component library expanded to 10+ modules
- [ ] Outreach pipeline running at 40 personalized messages/week
- [ ] Pricing readiness: moving from starter ($2K) to growth tier ($5K+)
